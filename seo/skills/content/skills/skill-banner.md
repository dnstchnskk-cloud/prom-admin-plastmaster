# 📝 Скіл: Текст для банера/акції — plastmaster.prom.ua

## Призначення
Генерація текстів для банерів, каруселей та акційних блоків на Prom.ua та соцмережах.
Коротко, цепляє, без пафосу. 3 варіанти під різний тон.

---

## Структура банера

### Заголовок
До 5 слів. Головна вигода або інтрига. Без знаків оклику якщо не потрібно.

### Підзаголовок
До 10 слів. Конкретика: що, скільки, умови, дедлайн.

### CTA-кнопка
2–3 слова. Дія + результат. Наприклад: "Обрати панелі", "Отримати знижку", "Дивитись каталог".

---

## Шаблон запиту до Claude

Напиши 3 варіанти тексту для банера магазину plastmaster.prom.ua.

Акція/товар: [опис акції або товару]
Тон: [коротко і цепляє / дружній / терміновість]
Платформа: [Prom.ua / Instagram / Facebook]

Формат кожного варіанту:
- Заголовок (до 5 слів)
- Підзаголовок (до 10 слів)
- CTA-кнопка (2–3 слова)

Вимоги: без пафосу, без "акція", "розпродаж" як єдиного аргументу.
Акцент на вигоді для покупця.

---

## Правила

- Уникати: "Найкраща ціна!", "Неймовірна акція!", "Тільки у нас!"
- Заголовок = вигода або питання, яке чіпляє
- Підзаголовок = конкретика (розмір знижки, термін, умова)
- CTA = дія, не "Натисніть тут"
- 3 варіанти = 3 різні підходи, не одне й те саме іншими словами
